# OctoAcme Project Management Docs

This folder contains OctoAcme’s project management guidance, from starting an initiative through delivery, release, and continuous improvement. Use this README to find the relevant process document; each linked document remains the source of detailed guidance.

## Project management process summary

OctoAcme uses a customer-first, iterative approach with clear ownership and data-informed decisions. Work begins by validating the business need, identifying stakeholders, defining success measures, and deciding whether to proceed. Approved initiatives are planned by shaping and prioritizing the backlog, estimating work, agreeing on a Definition of Done, and identifying milestones, risks, and dependencies. During execution, teams track work on a project board, use small reviewed pull requests, test changes, and communicate progress and blockers. Releases require acceptance criteria and CI checks to pass, release notes and rollback plans to be ready, and post-deployment verification. Teams close the loop through retrospectives, recording and following up on improvement actions. Risks and stakeholder communications are monitored throughout the lifecycle.
